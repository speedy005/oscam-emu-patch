# 🇩🇪 Deutsch

## ✨ Überblick

**OSCam-Emu** ist ein Erweiterungsmodul für den OSCam-Server, das Emulator-Unterstützung und zusätzliche Funktionen bereitstellt.

Als Alternative kann **OSEmu** verwendet und als Reader in einen regulären OSCam-Server eingebunden werden.

# 🇬🇧 English

## ✨ Overview

**OSCam-Emu** is an addon module for the OSCam server that provides emulator support and additional functionality.

Alternatively, **OSEmu** can be used as a reader with a standard OSCam server.
